## Descrizione del Progetto
Questo repository ospita lo sviluppo di un **sistema di visualizzazione** dedicato all'analisi di modelli neurali (in particolare architetture **GPT**) applicati alla **Pianificazione Automatica** (Automated Planning).
---

## Obiettivi
Il progetto si focalizza su tre aree principali:
1.  **Studio di Tecniche di Visualizzazione:** Analisi delle migliori metodologie per rappresentare l'interpretabilità di modelli GPT in contesti di reasoning.
2.  **Implementazione del Visualizzatore:** Sviluppo di un tool desktop modulare e interattivo.
3.  **Testing e Validazione:** Verifica delle capacità del modello su problemi e piani in domini di pianificazione classica (es. Blocksworld, Logistics).

---

## Tech Stack
Attualmente il progetto è sviluppato mantenendo le dipendenze al minimo:

* **Linguaggio:** Python 3.11.x
* **Interfaccia Grafica:** PyQt6

---

## Installazione e Avvio

1.  **Clona il repository:**
    ```bash
    git clone [https://github.com/tatoken/GPTviz.git](https://github.com/tatoken/GPTviz.git)
    cd GPTviz
    ```

2.  **Installa le dipendenze:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Avvia l'applicazione:**
    ```bash
    python main.py
    ```
